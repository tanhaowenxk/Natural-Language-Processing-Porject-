# Natural-Language-Processing-Porject-

This repository contains code for a project, where I was largely tasked with comparing multiple different text vectorisation methods, and fine tuning a BERT model to achieve an accuracy of 97%,



Cleaned the dataset provided by the school for the project.

Used my Resume to the dataset and did data cleaning for the updated dataset.

Proceeded on to attempt all different vectorisation methods that the school have taught and compared them based on the cosine similarity of the other resumes to my resume (required by the school).

Then proceeded to fine tune BERT model, unappended my resume and split the dataset into train and val, letting the BERT model achieve a high enough accuracy.
